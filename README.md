# 🚗 Escape Road Game

A fun and simple HTML5 mini game where you dodge obstacles using keyboard controls.

## 🎮 Features
- Smooth car movement with keyboard arrows  
- Increasing difficulty as you play  
- Simple and clean UI  

## 🧠 Tech Stack
- HTML  
- CSS  
- JavaScript
